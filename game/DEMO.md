# Five-minute demo plan

1. **0:00–0:30 — The hook.** “The world lost its voice. Your hands can bring it back.” Show the title and one short cinematic beat.
2. **0:30–1:20 — A real adventure.** Move/jump, discover the first shrine, and break the boulder with Force. Explain that signs are powers layered onto normal controls.
3. **1:20–2:00 — The central interaction.** Show casting focus and Shield. If actual model calibration has passed, demonstrate the camera. Otherwise clearly demonstrate keyboard mock input and name webcam recognition as unfinished.
4. **2:00–2:45 — Two partners.** Ask Luma for a contextual hint. With configured/tested services, show Gemini's response and Gradium narration with captions. Do not label an authored fallback as a live model response.
5. **2:45–4:15 — The payoff.** Use a saved local run to reach the Guardian; reflect its projectile with B and strike with A. Finish the restoration sequence and show the crystal reward.
6. **4:15–5:00 — What ships.** Show the free itch.io page, source repository, saves, five hidden stars, and replay. Explain that the other worlds extend the same power system.

Before presenting: check audio once, close unrelated tabs, use a tested browser, confirm the backend is awake, and retain keyboard controls as the reliable input path. Save inspection/dev manipulation must never be presented as a completed normal playthrough.
