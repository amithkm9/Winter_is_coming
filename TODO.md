# Winter is Coming — delivery status

Implemented means a feature exists with relevant automated checks. It does not claim a complete physical-device playthrough or verified sign recognition.

## Implemented

- [x] Supplied opening film with tap-to-start, pause, mute, skip and failure recovery; defer 3D loading until playback ends.
- [x] Three students, persistent chapter map, safe training and five playable prototype missions.
- [x] Sequential unlocks, separate mission saves, truthful training skip and scoped adventure reset.
- [x] Enter/phone ENTER interactions, first/third-person views, procedural movement and foot-contact effects.
- [x] Scanner countdown, caught screen, checkpoint retry and retained completed objectives.
- [x] Local ASL reference images, safe Study view, rehearsal and explicit simulated-input buttons.
- [x] Independent touch movement/look, responsive layouts, reduced-motion and performance settings.
- [x] Procedural sound/music with pause, visibility, volume and disposal safeguards.
- [x] Bundled MediaPipe, actual H5 warmup/inference, stale-result rejection and unverified model status.
- [x] Server-side Gemini/Gradium adapters with labeled fallback; packages exclude secrets/model weights.

## Required before a validated release

- [ ] Play the entire campaign with normal browser controls: routes, collision, retries, characters, saves and Continue.
- [ ] Test actual iPhone/Android devices: touch, rotation, sustained frame rate, audio, film, camera and background/resume.
- [ ] Test the final itch.io upload and hosted HTTPS backend, including iframe camera policy, CORS and denied/offline recovery.
- [ ] Supply valid Gemini/Gradium credentials and demonstrate real API requests before claiming partner usage.
- [ ] Recover/verify model label order and measure real-hand performance, false positives, orientation, lighting and capture-rate compatibility.
- [ ] Obtain qualified review of sign-language references/instructions; do not report model confidence as accuracy.
- [x] Use the supplied subtitled opening film, preserving its picture/audio and keeping controls outside the picture.
- [ ] Review subtitle timing and readability during real-device playback.
- [ ] Complete hardware WebGL visual QA and listening checks; record measured device/settings performance.
- [ ] Confirm publication rights for supplied film/audio and model; retain third-party attribution.

## Further production

- [ ] Replace prototype characters with authored meshes/rigs and tested animation clips.
- [ ] Expand later chapters beyond the common terminal framework: moving bridges, spatial light/growth puzzles, reflector combinations and a distinct multi-phase finale.
- [ ] Tune cues, rewards, difficulty and pacing from first-time player observations.
